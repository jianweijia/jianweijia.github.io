This is Jianwei Jia's personal academic website, built with Jekyll on the al-folio theme and deployed to GitHub Pages at <https://jianweijia.github.io/>.

## Update log in Notion

The site is tracked on the Notion page "Personal Website Track":
<https://app.notion.com/p/27cc8a2bb23580789046d03bb0ac7961>

Every time you update the website in a session, add one new subpage under that page to log the update.

- Create the subpage with the Notion connector, using the page above as the parent.
- Title it with the date and a short summary, e.g. `2026-11-20 Add SSCL paper`.
- In the body, list what changed, which files were touched, and the commit or pull request link.
- Write the log in Chinese, matching the rest of the Notion page.
- One subpage per session of updates, not one per commit.

If the Notion connector is not available in the session, say so at the end instead of skipping the log silently.

The same Notion page also has a "项目结构" table mapping what to change to which file. Keep it in sync when you add or rename top-level content folders or data files.
